# Contribution guidelines

Pull requests are welcome. To add something:

- It should be a service, device or tool a person can use for their own health without a referral. Software for clinics and hospitals belongs in other lists.
- Add one entry per pull request, in the section it fits best, in alphabetical order.
- Use the format `[Name](link) - Description.`
- Keep the description to one factual line about what it does. Leave out prices, discount codes and health claims.
- Link to the product's own site, or to the GitHub repo for open-source tools.
- If you work on what you're adding, say so in the pull request.

I'll remove entries that shut down, stop taking customers or turn out to be inaccurate. Open an issue if you spot one.
